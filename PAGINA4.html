Conceptos Basicos

  • Dominio:

    • En el contexto de HTML y desarrollo web, el término "dominio" se refiere a la parte principal de una URL que identifica de manera única un sitio web. Por ejemplo, en la URL

  • Sub dominio:

    • Crear un subdominio en HTML implica configurar tu servidor web y el DNS de tu dominio

  • URL:

    • Es una referencia o dirección utilizada para acceder a recursos en Internet. Es un concepto fundamental en el desarrollo web, junto con el hipertexto y HTTP. Las URL son el mecanismo utilizado por los navegadores para recuperar cualquier recurso publicado en la web

  • DNS:

    • El sistema de nombres de dominio (DNS) es el directorio telefónico de Internet

  • Hosting:

    • es un servicio que permite almacenar y hacer accesible tu sitio web en Internet.

  • FTP:

    • es un protocolo de red que permite la transferencia de archivos entre un cliente y un servidor a través de una red

  • HTTP:

    • es el protocolo de transmisión de información de la World Wide Web, es decir, el código que se establece para que el computador solicitante y el que contiene la información solicitada puedan “hablar” un mismo idioma a la hora de transmitir información por la red

  • HTTPS:

    • El protocolo de transferencia de hipertexto seguro (HTTPS) es la versión segura de HTTP, que es el principal protocolo utilizado para enviar datos entre un navegador web y un sitio web

  • W3C:

    • El W3C define las especificaciones de HTML y otros lenguajes relacionados, como CSS y XML

  • UTF-8:

    • es el pegamento invisible que permite que la web, las aplicaciones, las bases de datos y los sistemas modernos hablen el mismo idioma, sin importar el alfabeto, los símbolos o los emojis

  • HTML5 y su estructura

    • Una de las principales ventajas de HTML5 es la inclusión de elementos semánticos, o marcados semánticos, que nos ayudan a definir las distintas divisiones de una página web
